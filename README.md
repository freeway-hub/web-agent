# Web Agent

A local MCP agent that gives compatible clients access to files, terminals, processes, search, editing, and system tools.

## Features

- File and directory management
- Terminal and process control
- Search and editing
- PDF, document, spreadsheet, and image support
- Configuration and system information
- MCP UI resources

## Installation

Install the distribution directly from the public GitHub repository:

```bash
npm install github:freeway-hub/web-agent
```

## Run

Start the local device agent:

```bash
npx web-agent-device
```

Keep the process running while the MCP client is connected.

## Compatibility

Designed for MCP-compatible clients and integrations.
